# Agent docs — таблица маршрутизации

L1b-документация для AI-агента (протокол claude-memory-3layer). Читай на лету — то,
что нужно под задачу. Точка входа — [`../CLAUDE.md`](../CLAUDE.md).

## Какой файл читать под какую задачу

| Задача                                                    | Файл                                                                    |
|-----------------------------------------------------------|-------------------------------------------------------------------------|
| Натолкнулся на странность «выглядит сломанным / странным» | [gotchas.md](gotchas.md)                                                |
| Непонятное имя класса/файла/термина, аббревиатура         | [glossary.md](glossary.md)                                              |
| Кто вызывает сервис, модель угроз, статус легаси-решений  | [context.md](context.md)                                                |
| Правлю самообновление или Composer-цикл                   | [gotchas.md](gotchas.md) + [../docs/TECHNICAL.md](../docs/TECHNICAL.md) |
| Нужна глубокая механика (события, апдейтер, миграции)     | [../docs/TECHNICAL.md](../docs/TECHNICAL.md)                            |
| Понять структуру каталогов и подсистем                    | [../docs/PROJECT.md](../docs/PROJECT.md)                                |
| Список багов/уязвимостей с локациями и фиксами            | [../docs/BUGS.md](../docs/BUGS.md)                                      |
| План улучшений (сопровождаемость, безопасность)           | [../docs/RECOMMENDATIONS.md](../docs/RECOMMENDATIONS.md)                |
| Онбординг / сводка состояния проекта                      | [../docs/AUDIT.md](../docs/AUDIT.md)                                    |

## Соотношение L1b и аудита

- `.claude-docs/` (этот каталог) — **операционные знания для агента**: ловушки,
  термины, контекст вызова. Стабильны между задачами.
- `../docs/` — **результаты аудита** (Obsidian MOC от 2026-06-18): сводка, структура,
  баги, рекомендации. Глубокий справочник.

Ссылки на баги (`B1`, `S1`…) ведут в [../docs/BUGS.md](../docs/BUGS.md).
